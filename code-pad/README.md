# Code Pad

A code editor for practising on a phone. It is one HTML file with no build step.

## Features

- Works with your phone's own keyboard: no extra key bar, the whole screen is for code
- Closes brackets and quotes for you, indents new lines, and removes the indent when you type a closing bracket
- Syntax highlighting for JavaScript, Python, HTML, CSS, C, C++, and Java
- **Run**: JavaScript runs in a sandbox and prints to a console. HTML shows a live preview.
- Lets you keep several files, saved automatically in your browser
- Text size, indent width, and light/dark theme settings
- With a hardware keyboard: Tab / Shift+Tab, Ctrl+Enter to run, Ctrl+/ to comment, Ctrl+D to duplicate

## Use it on your phone

1. Open `index.html` in your phone's browser. You can host it with GitHub Pages (Settings → Pages → deploy from this branch), then go to `/code-pad/`.
2. Use **Add to Home Screen** so it opens full screen like an app.
